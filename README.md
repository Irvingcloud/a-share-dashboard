# A股市场阶段分析 · 网页版

一个本地运行的网页看板，四块数据自动抓取、自动计算，直接给出市场所处阶段：

| 模块 | 看什么 | 判断什么 |
|---|---|---|
| 一、市场广度与量能 | 宽广度、阿姆士 TRIN、额价差、成交额 | 1–3 天的超跌反弹 / 冲高回落 |
| 二、现货端 | 龙头宽基 ETF 份额变化（净申购）与成交额 | 是否真有资金进场（最接近“护盘痕迹”） |
| 三、中期情绪 | 股指期货基差（近月 / 当季 / 远月） | 对冲压力与中期方向 |
| 四、外围与大盘 | 纳指期货 NQ、纳指现货、上证、标普期货 ES | 隔夜外盘情绪对 A 股的传导 |
| 五、综合 | 四者交叉验证 | 市场阶段结论 |
| 六、历史记录 | 每日快照自动落盘（含「盘面简述」） | 回看趋势演变 |

> 版块顺序按重要性排：先看当日盘面统计（广度/量能），再看资金（ETF），再看中期（期指），最后看外围。

数据源 AKShare（新浪财经 / 上交所 / 乐咕乐股），全部免费、无需 API Key。

双击 **`启动分析页面.bat`**：会先检测服务是否在跑，已在跑就直接开浏览器；没在跑就拉起来、等 8 秒再打开页面。

### 访问地址
- 电脑本机：http://localhost:8501
- 手机 / iPad（同一 WiFi）：http://192.168.10.85:8501
  （IP 若变化，在电脑执行 `ipconfig` 查看 WLAN 的 IPv4 地址）

### 打不开时按顺序查（90% 是服务没启动）
1. 命令行执行 `Get-NetTCPConnection -LocalPort 8501 -State Listen`，**没输出＝服务没跑** → 双击 bat

## 二、各模块怎么读

### 1. 市场广度与量能（短线位置）
| 指标 | 含义 |
|---|---|
| 市场宽广度 | 上涨家数 ÷ 涨跌家数合计，>85% 普涨 <15% 普跌 |
| 阿姆士 TRIN | (涨家数/跌家数) ÷ (涨成交额/跌成交额)，低＝涨股量能集中 |
| 上涨额占比 | 上涨股成交额 ÷ 涨跌股成交额合计 |
| 额价差 | 上涨额占比 − 上涨家数占比，负＝资金偏小票，正＝偏权重 |

**核心是背离**：普跌（广度<15%）＋TRIN<0.5＝超跌反弹条件；普涨＋TRIN>1.2＝冲高回落风险。只管 1–3 天，不是反转信号。

### 2. 现货端（ETF 份额）
- **份额增加＝净申购**（真有资金进来），减少＝净赎回
- **成交额不能替代份额**：成交额是一买一卖对撞，会被套利、调仓放大；份额才是净流入
- 8 只龙头宽基：510050 上证50、510300/510310/510330 沪深300、510500/512500 中证500、512100 中证1000、588000 科创50
- 信号：合计当日净申赎 > +60 亿判为「强净申购」，> +15 亿「温和净申购」，< −15 亿「净赎回」
- **注意 T+1**：份额次日才发布，页面显示“最新份额日期”，今天的数据明天能查到

### 3. 中期情绪（期指基差）
- **近月贴水率** = 基差 ÷ 现货点位，不年化，最接近真实折价
- **当季年化** = 把折价折算成一年，中期情绪的主指标。近月合约临交割会被机械放大约 3–12 倍，所以只看当季
- **期限形态**：近月 → 当季 → 远月比大小
  - 远月更深（曲线下行）＝ 市场对中期定价更谨慎，对冲压在远月
  - 远月更浅（曲线修复）＝ 中期预期在改善
- 图表横轴月份已改为中文（如「2026年07月」）

### 4. 外围与大盘
| 指标 | 取数口径 | 怎么用 |
|---|---|---|
| 纳指期货 NQ | 外盘期货日线最新一根（含亚洲时段报价），涨跌幅对比前一交易日收盘 | 反映“美股盘后到 A 股开盘”之间风险偏好的实时变化 |
| 纳斯达克指数 | 美股最近一个交易日的收盘 | 隔夜已经发生的涨跌，是 A 股开盘情绪的起点 |
| 上证指数 | A 股当日实时 | 与外围对照看“有没有跟跌 / 逆势” |
| 标普期货 ES | 同 NQ | 更偏权重的美股整体风险偏好 |

**关键看背离，不是绝对值**：隔夜纳指大跌、但纳指期货次日反弹 >1%，说明恐慌在盘后修复，对 A 股未必是利空；两者同向下跌才是真压制。判断规则写在代码里（`nq_chg > 1 且 ix_chg < -1` → 情绪修复）。

### 5. 综合结论
页面顶部先给一句「今日盘面」速读（期指情绪｜ETF 资金｜短线量能｜外盘），下方再把四条线展开：ETF 净申购 + 期指贴水收窄 + 指数企稳，三者同向才可信；只有一条容易误判。

### 6. 配色规则（红=利好，绿=利空）
网页指标卡、明细表、历史记录、Excel 全部用同一套阈值，改一处就全局生效（`market_core.py` 里的 `_SCALE`）。

| 指标 | 深红 大利好 | 红 利好 | 黑 中性 | 绿 利空 | 深绿 大利空 |
|---|---|---|---|---|---|
| 市场宽广度 | ≥85% | ≥70% | 40–70% | ≥25% | <25% |
| 阿姆士 TRIN | ≤0.70 | ≤1.00 | ≤1.20 | ≤1.50 | >1.50 |
| 上涨额占比 | ≥65% | ≥55% | 45–55% | ≥35% | <35% |
| IF 当季年化基差 | ≥+3% | ≥+1% | −4% ~ +1% | ≥−8% | <−8% |
| 近月贴水率 | ≥+2% | ≥+0.5% | −1.5% ~ +0.5% | ≥−3% | <−3% |
| ETF 当日/近5日净申赎 | >+60 亿 | >+15 亿 | −15 ~ +15 亿 | >−60 亿 | ≤−60 亿 |
| 涨跌幅（上证/纳指/ETF） | ≥+1.5% | ≥+0.5% | −0.5% ~ +0.5% | ≥−1.5% | <−1.5% |
| 中期情绪 | 过热 | 偏乐观 | 中性 | 悲观 | 极度悲观 |
| 期限形态 | — | 曲线修复 | 相对平坦 | 曲线下行 | — |

两条使用提醒：

- 颜色只表示「这个指标当下偏多还是偏空」，**不是买卖信号**。今天就是典型：广度 85.6% 深红（普涨），但 TRIN 1.44 是绿（跌股吃走了更多成交额），两者打架＝冲高回落风险。
- 成交额、日期、盘面简述这类没有方向性的字段不染色，避免全表花花绿绿。

### 怎么用

### 关掉自动记录

## 四、定时自动抓取与自动关机（新增）

不开网页也能每天记一条，抓完自动关机。

### 已注册的计划任务
| 项 | 值 |
|---|---|
| 任务名 | `A股市场数据每日抓取` |
| 时间 | 周一至周五 **22:30** |
| 执行 | `python daily_snapshot.py`（用 Python 3.12 解释器） |
| 身份 | 当前用户，**只在用户登录时运行** → 不需要输开机密码 |
| 失败重试 | 错过时间会自动补跑（StartWhenAvailable），单次最长 30 分钟 |

改时间：任务计划程序里双击该任务改触发时间，或命令行
```
schtasks /change /tn "A股市场数据每日抓取" /st 21:30
```

### 为什么定在 22:30
A 股已收盘、数据结算完毕；22:30 北京时间正好是美股开盘（9:30 ET），顺手把纳指期货的实时开盘反应也记进当天那一行。想改成收盘后（15:10）也行，只是外盘那一列意义不大。

### 脚本会做什么
1. 查交易日历，**非交易日直接退出**（不写记录、不关机，所以节假日不会误关）
2. 抓期指 / ETF 份额 / 广度 / 外盘 → 算指标
3. 写入 `历史记录/市场阶段历史.csv` 与 `.xlsx`（同一天只保留最新一条）
4. 写日志到 `日志/定时抓取日志.txt`
5. 关机倒计时 **120 秒**，期间可取消

### 想临时不关机
- 跑一次：命令行执行 `shutdown /a` 取消
- 长期：在 `历史记录` 文件夹里新建一个空文件 `今天不关机.txt`（脚本检测到就跳过关机，删掉即恢复）
- 彻底关掉：改 `daily_snapshot.py` 顶部 `SHUTDOWN = False`
- 抓取失败默认**不关机**（`SHUTDOWN_ON_FAILURE = False`），方便你回来排查


## 六、已知限制

1. **非交易日无实时数据**：显示最近交易日收盘值，页面会标「数据日期」，不报错。
2. **全市场快照偶发限流**：`stock_zh_a_spot_sina` 要拉 5000+ 只股票（10–15 秒）。失败时自动降级为“只算涨跌家数”，量能列显示 —，不是 bug。
3. **ETF 份额仅覆盖上交所品种**：深市（159 开头，如 159915 创业板 ETF）交易所接口不带历史日期，暂时没纳入。
4. **期指 ≠ 国家队**：期指持仓主体是券商自营、私募中性、量化与套利盘，无法识别账户归属。ETF 份额净申购是目前最接近护盘资金的公开证据，但仍可能是机构配置/套利。
5. **分红季失真**：5–7 月成分股分红会让贴水被动加深，年化基差系统性偏负。
6. **外盘只有日线粒度**：纳指期货 NQ 用外盘日线接口取最新一根（约 5–15 分钟更新一次，不是逐笔），拿来做“日级别判断”够用；若要分钟级盘口需付费行情。
7. **纳指现货有交易时差**：A 股白天时美股是收盘状态，所以「纳斯达克指数」永远是上一交易日值，页面上会标日期。
8. **定时任务依赖电脑开机 + 用户登录**：选了「只在用户登录时运行」（不需要密码），如果 22:30 时电脑关机或没人登录，本次就不跑；但只要之后开机登录，会补跑一次（StartWhenAvailable）。
9. **关机前 120 秒可取消**：突然弹关机提示就执行 `shutdown /a`。
